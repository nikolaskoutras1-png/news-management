# News Management

Starter για το Σύστημα Διαχείρισης Ειδήσεων του εργαστηρίου Τεχνολογίας Λογισμικού.

## Ομάδα

Τα στοιχεία των μελών συμπληρώνονται στο `docs/team.md`.

## Περιεχόμενα

- `ASSIGNMENT.md`: η εκφώνηση του backend project.
- `docs/overview.md`: σύντομη περιγραφή και αρχικές λειτουργίες.
- `docs/team.md`: στοιχεία ομάδας και τρόπος συνεργασίας.
- `src/README.md`: θέση για τον κώδικα στα επόμενα εργαστήρια.

## Εργαστήριο Git

Χρησιμοποιούμε ένα τοπικό αντίγραφο ανά δυάδα. Εκτελούμε τις ασκήσεις με τη σειρά του οδηγού.
Η πρώτη γραμμή αυτού του αρχείου χρησιμοποιείται στην άσκηση σύγκρουσης.
