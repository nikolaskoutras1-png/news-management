# Project overview

Το έργο αφορά ένα backend για τη δημιουργία, την επιμέλεια, τη δημοσίευση και την αναζήτηση ειδήσεων.

## Αρχικές λειτουργίες

- Σύνταξη και επεξεργασία πρόχειρων ειδήσεων από δημοσιογράφους.
- Υποβολή ειδήσεων για έλεγχο από επιμελητές.
- Έγκριση ή απόρριψη με αιτιολογία.
- Αναζήτηση δημοσιευμένων ειδήσεων από επισκέπτες.

Η πλήρης εκφώνηση βρίσκεται στο `ASSIGNMENT.md`.
